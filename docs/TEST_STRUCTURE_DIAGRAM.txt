                            QUICK COMMAND REFERENCE

Run all tests:
  pytest tests/

Run by category:
  pytest tests/unit/                    # All unit tests
  pytest tests/integration/             # All integration tests
  pytest tests/e2e/                     # All e2e tests

Run by functionality:
  pytest tests/unit/encoding/           # Encoding tests
  pytest tests/unit/delimiter/          # Delimiter tests
  pytest tests/unit/normalizers/        # Normalization tests
  pytest tests/unit/validators/         # Validation tests
  pytest tests/unit/schemas/            # Schema tests

Run by converter:
  pytest tests/integration/converters/  # General converter
  pytest tests/integration/postmortem/  # Postmortem converter

Run with filters:
  pytest tests/ -k "normalization"      # Tests matching pattern
  pytest tests/ -v                      # Verbose output

Run in parallel (requires pytest-xdist):
  pytest tests/ -n auto                 # Auto-detect CPU cores

Run with coverage:
  pytest tests/ --cov=src --cov-report=html
