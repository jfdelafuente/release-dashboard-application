                        REFERENCIA RÁPIDA DE COMANDOS

Ejecutar siempre desde el directorio 'converters/':
  cd converters

Ejecutar todos los tests:
  pytest tests/ -v

Ejecutar por categoría:
  pytest tests/unit/ -v                 # Pruebas unitarias
  pytest tests/integration/ -v          # Pruebas de integración
  pytest tests/e2e/performance/ -v      # Benchmarks de rendimiento

Ejecutar por componente:
  pytest tests/unit/report_generator/   # Reportes PowerPoint
  pytest tests/unit/normalizers/        # Normalizadores
  pytest tests/unit/schemas/            # Esquemas de datos

Ejecutar en paralelo:
  pytest tests/ -n auto

Medir cobertura de código:
  pytest tests/ --cov=src --cov-report=term-missing
